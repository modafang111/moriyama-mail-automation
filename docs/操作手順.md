# 手動操作の手順

いまはプログラムが途中までです。この文書どおり、手で操作してください。通知メールはこのプログラムからは送りません。MyASPへの本番配信も、まだ実際には送りません。

画面のボタン名に合わせています。配置がまだのときは [LOCAL_SETUP.md](LOCAL_SETUP.md) を先に見てください。ローカルの Cursor から実行するときは [CURSOR.md](CURSOR.md) です。

## 1. 担当者画面を開く

Cursor の場合（コマンドの貼り付けは不要）:

1. このフォルダを Cursor で開く
2. 初回は `02_install.bat` をダブルクリック
3. 「実行とデバッグ」で **担当者画面** を開始する（F5）

バッチだけの場合（リモートデスクトップ向き）:

1. フォルダをエクスプローラーで開く
2. 初回は `02_install.bat`、毎回は `03_start.bat` をダブルクリック
3. 「森山メルマガ配信支援」の画面が出る

## 2. ウェブの専用フォームを開く

依頼はブラウザの専用フォームから受けます。

1. 担当者画面の左の「ウェブフォームを開く」を押す
2. ブラウザが開く（アドレスは `http://127.0.0.1:8787/` ）
3. 顧客にこの画面を使ってもらう

担当者画面を出さずにフォームだけ開くときは `open_web_form.bat` をダブルクリックします。黒い窓は閉じないでください。閉じるとフォームが止まります。

社外のお客さまが自分のパソコンから開く公開URLは、まだ決まっていません。今は担当者のパソコン上のブラウザで開きます。

### フォームに書くこと

| 項目 | 内容 |
| --- | --- |
| MyASPプラン | テストプラン または 本番プラン（必須） |
| メール件名 | 配信メールの件名 |
| メール本文 | 本文。ドライブのURLは後から担当者が入れてもよい |
| 備考 | 任意 |
| 配信用資料 | PDFなど。任意 |
| 追加する宛先のファイル | 任意 |
| 今回だけ送らない宛先のファイル | 任意。リストから名前は消しません |

「担当者へ依頼を送る」を押すと受付番号が出ます。この画面から配信は行われません。

ブラウザを使わないときは、担当者画面の「依頼を代わりに入力」から同じ内容を入れられます。

## 3. 案件を確認する

1. 担当者画面の左の一覧から、今の案件を選ぶ
2. 件名、本文、プランを確認する
3. 直したら「件名・本文を保存」を押す

## 4. 資料をドライブへ載せる

1. 資料が未選択なら「資料を選択」
2. 「Driveへアップロード」を押す
3. 共有URLが出たら「本文へ挿入」を押す

いまの初期設定はモックです。本物のGoogleドライブには上がりません。画面の流れを確認するためのものです。本物のドライブを使う設定は、後から `.env` で切り替えます。

## 5. 宛先を読み込む

フォームでファイルを付けていなければ、ここで読み込みます。

- 「追加する宛先CSV」… 配信対象に足す
- 「今回だけ送らないCSV」… その配信のときだけ送らない。リストからは消さない

列名を聞かれたら、メールアドレスの列名を入れます。列が1つだけ、または見出しが無いファイルは空欄で構いません。

アドレス一覧は画面に出ません。件数だけ出ます。

## 6. テスト配信（確認）

1. 配信モードは最初から「テスト配信」になっている
2. 「配信前の内容を確認」で件名と件数を見る
3. 「配信を実行」を押す

テスト配信は `.env` の `TEST_RECIPIENTS` に書いた確認用アドレスにだけ送る前提です。今は未設定なので、実行できないことがあります。その場合は確認用アドレスが決まるまで待ってください。

MyASP実連携はまだモックです。読者全体には送られません。

## 7. 本番の予約配信（確認まで）

即時の本番配信は使いません。本番は予約の扱いです。

1. 配信モードで「本番配信（予約…）」を選ぶ
2. 「件名・本文を保存」
3. 「配信前の内容を確認」で、件名、本番であること、対象件数、今回除外の件数、共有URLを見る
4. 「配信を実行」のあと、確認画面で **本番配信を承認** と入力する
5. 承認しない限り送りません

本番済みの案件は、同じ案件では再度本番できません。

いまはモックなので、MyASPの読者には実際に送られません。確認画面までの手順を手で確認してください。本物のMyASP操作は、決まるまで管理画面で手作業です。

## やってはいけないこと

- 確認画面を飛ばして本番を送ること
- テストのつもりで本番モードのまま実行すること
- 本番済み案件をもう一度本番にすること
- `.env` や顧客CSVをGitHubに載せること

## まだプログラムがやらないこと

- 通知メール（共通の通知処理ができてから）
- MyASPへの実配信
- 社外から開く公開URLの用意
- CSV列名の固定
