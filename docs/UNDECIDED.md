# 未確定事項

固定仕様にしない項目です。決まり次第、受付アダプタ・CSVパーサ・MyASPゲートウェイだけを足します。

## 依頼受付

- 受付チャネル（メール、Googleフォーム、専用Webフォーム、その他）
- 通知以外に、依頼メール本文を自動取込するか
- 添付PDFの受け取り方
- 依頼者と配信対象データの送り方

第1段階は手動で案件を作り、作成時に担当者へ通知メールを送れるようにするだけです。

## 配信対象データ

- CSVの列名
- 文字コード
- 追加・削除・除外が別ファイルか、1ファイルの区分列か
- メールアドレス以外に氏名などをMyASPへ渡すか
- 「削除」の意味（MyASPユーザー削除 / 配信解除）
- 「除外」の意味（今号だけ送らない / ラベル / 配信解除）

## メール本文

- Driveリンクを置く正式な目印や文言
- テキストかHTMLか
- MyASPの共通ヘッダー／フッターを使うか

暫定の挿入目印は `{{DRIVE_SHARE_URL}}` です。業務上の文言が決まれば差し替えます。

## MyASP / Google

- プラン、シナリオ、ログインURL
- 本番を即時にするか予約にするか
- DriveのフォルダID、共有範囲

## 通知

- 通知先アドレス
- SMTP（例: Gmailアプリパスワード）
- 依頼以外に、テスト完了・本番完了でも通知するか
